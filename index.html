Connecter mon jeu

Ton jeu envoie ses chiffres toutes les 15 secondes dans une base gratuite à toi (Firebase, de Google). Ce site les lit en direct. Compte 10 minutes la première fois.

Crée ta base Firebase (gratuit)

  1. Va sur console.firebase.google.com et connecte-toi avec ton compte Google.
  2. Créer un projet → donne-lui un nom (ex. stats-mon-jeu) → tu peux désactiver Google Analytics.
  3. Menu de gauche : Créer → Realtime Database → Créer une base de données → choisis Belgique (europe-west1) → Démarrer en mode verrouillé.
  4. Copie l'adresse affichée en haut de l'onglet Données (elle finit par firebasedatabase.app ou firebaseio.com).

Protège ta base

Option A — avec un secret (si tu en vois un) : roue dentée ⚙️ → Paramètres du projet → Comptes de service → Secrets de la base de données → passe la souris sur la ligne → Afficher → copie le code.

Option B — avec une clé (si la liste des secrets est vide) : c'est la méthode conseillée maintenant. Ta clé secrète est générée ci-dessous.

  1. Dans Firebase : Realtime Database → onglet Règles.
  2. Efface tout, colle les règles ci-dessous, puis clique sur Publier.
  3. À l'étape 3, laisse le champ « Secret » vide.
Règles à coller dans Firebase

Sans la clé, personne ne peut lire ni écrire dans ta base. Ne la mets pas dans une image ou une vidéo.

Colle-les ici

Ajoute les 2 scripts dans Roblox Studio

  1. Home → Game Settings → Security → active Allow HTTP Requests (et Enable Studio Access to API Services).
  2. Dans ServerScriptService : ajoute un Script nommé LiveAnalytics et colle le script serveur.
  3. Dans StarterPlayer → StarterPlayerScripts : ajoute un LocalScript nommé AnalyticsDevice et colle le script client.
  4. Lance le jeu dans Studio : la sortie doit afficher ✅ Connexion à Firebase OK et la ligne « Test depuis Studio » à droite passe au vert.
  5. Publie ton jeu. Dès qu'un joueur rejoint, l'onglet En direct s'allume.
